# IEEE-CIS Fraud Detection

## Problem Statement
Detecting fraudulent transactions from 590,540 
real-world financial transactions with severe 
class imbalance (3.5% fraud rate).

## Dataset
- Source: IEEE-CIS / Kaggle
- Train: 590,540 transactions x 434 features
- Fraud rate: 3.5%

## Approach
1. Exploratory Data Analysis (EDA)
2. Feature Engineering (velocity, behavioral, temporal)
3. XGBoost with class weight balancing
4. SHAP explanations for interpretability
5. FastAPI deployment for real-time scoring
